配置中心

与 AstrBot 插件配置（_conf_schema.json）共用同一份数据，两处修改互相同步。保存后插件会尝试热重载，无需重启 AstrBot。

首次使用请在「TypeSafe 判定」中填写 API Key，然后在「运行状态」页点一次连通性测试确认可用。其余 47 项均有可用默认值，可以先跑起来再逐项微调。

固定问答表

KeyReply 兼容的问答表。消息先经本地正则召回，命中才触发 Jev 审核，再由 LLM 围绕该条答案生成回复；未命中一律静默。

生效模式

由「配置中心 → 固定问答表 → 回复来源」决定
